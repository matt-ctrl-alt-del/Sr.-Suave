# Sr. Suave

Controils:
Controls:
W - Move Up
A - Move left
S - Move down
D - Move right

You are ordered by Sr. Suave to collect antique and powerful items in this unfamiliar world! Collect the items and return to Sr. Suave.

 Context: Here I tried to mix the concept from my previous games of tilemap movement but implemented them only on enemies so the players can have freedom of movement. I was quite unsatisfied with the art and some ui art were unused. However I have learned a lot of things with the project. I became more efficient such as learning to use Animated sprites as animations or transitions rather than relying on color rect scenes as transitions. Then I explored more in the movement and the overall flexibility of the features I am already using such as making a 5 item tracker instead of my usual 4 and looking if something breaks. It was a fun experience making the game.
